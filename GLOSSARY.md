# Glossary

| Term | Definition |
| --- | --- |
| **Ganesh Apa Panchang** | The authoritative physical almanac used as the primary source of truth for this platform. |
| **Panchang** | The five limbs of Hindu astrology: Tithi, Vaar, Nakshatra, Yoga, Karana. |
| **Aaj Vishesh** | "Today's Specials"; a curated list of daily observances including Vrats, Parvas, Shraddhas, and significant transit timings. |
| **Parana** | The specific auspicious time window for breaking a fast (Vrat) undertaken on the previous day. |
| **Bhadra** | A highly significant inauspicious period/interpretation corresponding to the Vishti Karana, which mandates explicit warnings in the daily broadcast. |
| **Pakshika Surya** | The Sun's transit (Rashi and Nakshatra) which remains relatively constant over a fortnight (Paksha). |
| **Suvichar** | The daily editorial quote or thought added by the Purohit at the end of the broadcast. |
| **Purohit Review** | The manual review phase where the domain expert inspects calculated/sourced data against the physical reference before publication. |
| **Purohit Decision** | The authoritative ruling made by the Purohit to resolve flagged discrepancies or edge cases in the data. |
| **Provenance** | The origin classification of a data point (e.g., calculated, source-referenced, externally sourced, editorial, Purohit-approved/decided). |
| **Transition** | The specific time at which an astrological element (like Tithi or Nakshatra) changes state during the current day. |
| **Golden Reference Dataset** | The dataset of historical WhatsApp messages representing the exact structural and terminological baseline of the platform's output. |
